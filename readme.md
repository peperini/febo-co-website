# Febo Co. Website

Febo Co. diseña experiencias de aprendizaje para empresas y personas.
Combinamos diagnóstico, capacitación y soluciones creativas a medida
para desarrollar capacidades y convertir el conocimiento en acción.
Trabajamos con cercanía, agilidad y expertise multidisciplinario.

**Aprender. Aplicar. Avanzar.**

## Acerca del proyecto

Sitio web de Febo Co. para presentar la marca, sus experiencias de
aprendizaje y sus soluciones para organizaciones y profesionales.

La dirección visual es minimalista, editorial, experimental,
inspiracional y creativa.

## Estructura del repositorio

```text
src/
  index.html        # Página principal
public/
  febo-folleto.pdf   # Folleto comercial
package.json        # Dependencias y comandos
vite.config.js      # Configuración de Vite
readme.md           # Documentación del proyecto
```

## Desarrollo local

Requisitos: Node.js y npm compatibles con Vite 7.

```bash
npm install
npm run dev
```

## Compilación

```bash
npm run build
```

Los archivos generados se guardan en `dist/`.
